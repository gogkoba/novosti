# Образцы выпусков

Файлы `2026-09-04.md` … `2026-09-08.md` — готовые выпуски за пять дней, вытащенные из `news.docx` (исходник с фотографиями к каждой новости, 12 МБ).

Каждый выпуск состоит из трёх блоков:

1. **Речь ведущего** — 700–900 слов, читается в эфире. Ориентир по структуре, переходам, длине новостей и порядку тем.
2. **Авторская статья** — колонка по одной новости дня, 450–600 слов. Ориентир по жанру, но тон в образцах горячее, чем требует `RULES.md` (раздел 4): ярлыки и сарказм из них не копировать.
3. **Новости на дату** — дайджест по рубрикам: заголовок + 1–3 предложения + ссылки на видео. Формат, который мы делаем в `01_digest.md`, подробнее (три абзаца на новость и ссылка на источник).

Что брать из образцов: порядок тем, ритм речи, вводную и заключительную фразы, длину новостей, названия рубрик.
Что не брать: штампы из стоп-листа `RULES.md` («переходим к тому, что волнует каждого из нас», «вот такой получился день», «это не просто поставка — это…»), ярлыки («киевский режим», «упёртые», «сателлиты»).
