# Новости — служба подготовки выпусков для канала в Max

Ежедневный цикл: сбор новостей → дайджест на проверку → речь ведущего → проверка → сохранение в git.
Все редакционные правила (тематика, источники, тон, стиль, форматы) — в `RULES.md`. **Читай его целиком перед любым шагом.**
Эталоны формата — в `examples/` (см. `examples/README.md`).

## Структура

```
CLAUDE.md          — этот файл: как работать
RULES.md           — редакционные правила (что, откуда, каким тоном, в каком виде)
examples/          — образцы готовых выпусков (речь, статья, дайджест) за 04–08.09.2026
output/ГГГГ-ММ-ДД/ — рабочие файлы выпуска за день
  01_digest.md     — дайджест 20–30 новостей на проверку
  02_speech.md     — речь ведущего (собирается из одобренных новостей)
  03_column.md     — авторская статья (если нужна в этот день)
```

## Команды (пользователь пишет одно слово — ты делаешь весь шаг)

| Команда | Что делать |
|---|---|
| `новости` / `дайджест` | Шаг 1. Собрать 20–30 новостей за последние 24 часа по `RULES.md`, записать в `output/<сегодня>/01_digest.md`, показать пользователю кратко (заголовки по рубрикам). Не спрашивать уточнений — действовать по правилам, вопросы задавать только если новостей объективно не хватает. |
| `речь` | Шаг 2. Прочитать `01_digest.md` с пометками пользователя (см. «Проверка» ниже), собрать из одобренных новостей речь ведущего в `02_speech.md` по формату из `RULES.md`. Показать целиком. |
| `статья` | Написать авторскую статью по одной новости дня (по умолчанию — по самой важной из одобренных, либо по указанной) в `03_column.md`. |
| `правки: ...` | Внести правки в последний созданный файл, показать только изменённые фрагменты. |
| `сохрани` | `git add -A`, коммит `Выпуск ГГГГ-ММ-ДД` (или `Выпуск ГГГГ-ММ-ДД: правки`), `git push`. |

Дата — сегодняшняя по системным часам (Москва). Если папка `output/<сегодня>/` уже есть — дополняй, не затирай без просьбы.

## Проверка дайджеста

В `01_digest.md` у каждой новости есть строка `- [ ] одобрено`. Пользователь ставит `[x]` у тех, что идут в речь, может дописать комментарий после галочки (`- [x] одобрено — короче, без цифр`). Новости без галочки в речь не попадают. Если ни одной галочки нет, а пользователь пишет `речь` — спроси, брать ли все.

## Жёсткие требования

- Ни одного выдуманного факта, цифры, цитаты, имени. Нет источника — нет новости.
- У каждой новости в дайджесте — ссылка на первоисточник. Ищи через веб-поиск, проверяй по двум источникам, если новость резонансная.
- Речь и статья — чистый текст без markdown-разметки, ссылок, скобок, эмодзи: их читают вслух.
- Стиль — по разделу «Язык» в `RULES.md`. Перед выдачей прогоняй текст по чек-листу из `RULES.md` и вычищай всё, что в стоп-листе.
- Не выдавай текст с вопросами «уточните…» внутри — принимай решение сам, а спорные места помечай в конце файла блоком `Примечания редактора`.
